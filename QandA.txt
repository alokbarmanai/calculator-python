#How can you Handle invalid input safely.?
Safe handling of invalid input in this project
This project handles invalid input in the parser layer, mainly in parser.py and the summary logic in summary.py.
Common pattern used
The code checks:

file exists
JSON can be loaded
expected fields exist
field types are correct
Why this is safe
It prevents:

crashes from missing files
invalid JSON parsing errors
wrong data structure
missing required keys
